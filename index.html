FolderFit Privacy Policy

Effective 18 October 2026

FolderFit is a Windows utility that keeps the Name column of File Explorer windows wide enough to show whole file names. It is published on the Microsoft Store by Brad Stone.

What FolderFit collects

Nothing. FolderFit does not collect, store or transmit any personal information. It has no account, no sign-in, no analytics and no advertising, and it never connects to the internet.

What FolderFit stores on your PC

FolderFit keeps two small files in your local application data folder (%LOCALAPPDATA%\FolderFit):

  • settings.ini: your minimum width, maximum width and check interval.
  • log.txt: a short activity log of the windows it resized, including the folder paths of those windows, so you can see what it did. This file never leaves your PC and is overwritten when it grows past 1 MB.

Both files are removed when you uninstall the app from the Microsoft Store.

What FolderFit accesses

To do its job, FolderFit reads the list of open File Explorer windows, the folder each one shows and the names of the files in it, using the same interface Windows provides to Explorer itself. It uses that information only to calculate column widths, in memory, and does not keep or send it anywhere other than the local log described above.

Third parties

No data is shared with anyone, because no data is collected.

Children

FolderFit is a general utility with no content, communication or data collection, and is suitable for all ages.
